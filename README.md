# diff_exp_of_PBMCs_in_IBD_patients_UC_patients_and_healthy_controls
Differential expression analysis on data from Stanford university. Peripheral blood mononuclear cells (PBMCs) from patients with Crohn's disease (CD), ulcerative colitis (UC), and healthy controls (HC) were profiled using  using single-cell RNA sequencing. In this repo, I analyze the resulting .rds file.
